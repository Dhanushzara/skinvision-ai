# Melanoma Detection App

A web application for detecting melanoma from skin lesion images using computer vision.

## features

- **Image Upload**: Upload high-resolution images of skin lesions.
- **Webcam Support**: Capture live photos directly from the browser.
- **Analysis**: Instant feedback on potential melanoma risk (Mocked/Simulated).

## Prerequisites

Before running this application, make sure you have the following installed:
- **Node.js** (v18 or higher)
- **npm** (usually comes with Node.js)

## How to Run

1.  **Open a terminal** in the project directory:
    ```bash
    cd c:\Users\SMILE\Downloads\Melanoma-Detect\Melanoma-Detect
    ```

2.  **Install Dependencies**:
    ```bash
    npm install
    ```

3.  **Start the Development Server**:
    ```bash
    npm run dev
    ```

4.  **Open the App**:
    The terminal will show a URL (usually `http://localhost:5000`). Open this in your browser.

## Troubleshooting

-   **'npm' is not recognized**: Ensure Node.js is installed and added to your system PATH.
-   **Upload fails**: Ensure you are using the latest version of the code with the multipart upload fix.
